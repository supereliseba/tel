# Strikketeljar

Ein enkel teljar til strikking, laga for mobil (Pixel 9 Pro XL).

> **Status:** Under arbeid. Prosjektet er nettopp starta, og koden er ikkje skriven enno.

## Kva appen skal gjere

- **Minus-knapp, tal og pluss-knapp.** Ikkje noko meir.
- **Hugsar talet** mellom kvar gong appen vert opna.
- **Nullstilling** av teljaren når du treng det.

## Design

- Ekstremt enkelt og reint.
- Store knappar som er lette å treffe med strikketøy i hendene.
- Stort og tydeleg tal midt på skjermen.

## Teknologi

- Rein HTML, CSS og JavaScript, utan rammeverk.
- Talet vert lagra i nettlesaren med `localStorage`.
- Kan leggjast til på heimeskjermen som app (PWA).
- Vert publisert med GitHub Pages.

## Køyre lokalt

Når koden er på plass, kan du opne `index.html` direkte i nettlesaren.
