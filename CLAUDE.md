# Strikketeljar

## Om meg
Eg lærer koding att etter 20 år. Har bakgrunn i Java og litt Linux.
Lærer no JavaScript, Git og GitHub.

## Korleis du skal jobbe med meg
- Svar på nynorsk.
- Forklar kva du gjer og kvifor, særleg ting som er nytt i JavaScript samanlikna med Java.
- Ta små steg. Ikkje skriv store mengder kode på ein gong.
- Spør før du legg til noko eg ikkje har bedt om.

## Om prosjektet
Ein teljar eg brukar når eg strikkar, på Pixel 9 Pro XL.

### Funksjon
- Tre element: minus-knapp, talet, pluss-knapp. Ikkje noko meir.
- Talet skal hugsast mellom kvar gong appen vert opna.
- Må kunne nullstille teljar når det trengst

### Design
- Ekstremt enkelt og reint.
- Store knappar som er lette å treffe med strikketøy i hendene.
- Stort, tydeleg tal midt på skjermen.

### Teknologi
- Rein HTML, CSS og JavaScript, utan rammeverk.
- Lagring med localStorage.
- Skal kunne leggjast til på heimeskjermen som app (PWA).
- Publiserast med GitHub Pages.
